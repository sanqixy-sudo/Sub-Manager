# 代理服务管理实现计划

本轮范围：保留现有订阅聚合，新增服务器接入、AnyTLS / VLESS / Trojan TLS 节点、服务端链式出站、用户与多套餐实例、独立凭据、流量回传和用户订阅入口。服务器端选择固定版本 sing-box 1.14.4；主控仍单容器、7777、/data。远程 Agent 是安装在节点服务器上的独立进程。

## 模块与契约

- app/control：独立数据表、加密秘密、套餐授权、配置生成、管理与 Agent API。现有组 Token 和缓存不变。
- agent：Linux systemd 一键安装，Python Agent 通过 HTTPS Pull 通信，仅执行经过校验的 sing-box 配置，无任意 shell 执行接口。服务器配对 Token 一次有效，运行 Token 只保存哈希。
- 所有协议使用 TLS；可上传证书或自动生成证书。Mihomo 输出固定证书指纹，sing-box 输出信任指定证书，不关闭 TLS 校验。
- 链式配置为节点入站路由到下一代理节点；检测环路、停用依赖和端口冲突。内部中转凭据与用户凭据分离，用户只在入口计费。
- 用户每次绑定套餐产生独立实例及节点凭据。空节点集就是零权限；模板更新同步节点范围。每实例周期、到期、额度独立。
- Agent 上报持久化累计字节，主控按服务器/实例/授权保存高水位，在一个事务内去重记账。正常采集周期 10 秒，额度执行存在一个采集/同步周期的延迟；失联超过 120 秒停止托管代理，避免长期绕过到期/额度控制。
- 用户门户使用独立会话与服务端所有权校验；订阅 Token 与管理、Agent 凭据互不通用。

## 实施与验收

1. V12 增量迁移并保持旧数据；数据库升级前自动备份。
2. 管理 CRUD、配对重放拒绝、Agent 权限隔离、证书匹配验证、节点链无环、套餐增删同步。
3. Agent 检查配置后替换、重启失败恢复上一配置，回传实际应用版本；保留未送达计数并幂等补报。
4. 新增服务器/代理节点/用户套餐管理页与用户门户，复用已有 Vue/Element Plus 样式。
5. 测试覆盖多租户资源越权、链路、到期/超额、周期重置、重放/乱序流量、密钥缺失、现有订阅回归。真实 sing-box 在本地验证 AnyTLS 多用户、链路和统计；Linux 安装脚本需单独验收，不能用模拟测试代替。

## 恢复

完整备份 /data（包括 secrets/control.key）。回滚旧版本必须恢复升级前 /data；仅换镜像不可写 V12。Agent 使用独立服务名和目录，不接管既有代理服务或改写防火墙。生产服务器尚未提供，不自动部署生产。
